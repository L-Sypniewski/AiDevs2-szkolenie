# Research Source Selection

Quick reference for choosing research tools based on topic type.

## Decision Matrix

| Topic Type | Primary Tool | Reason |
|------------|--------------|--------|
| .NET/C#/Azure | `microsoft-docs` | Official Microsoft content |
| Web content, blogs, docs | `web-search-prime` → `web-reader` | Search then fetch |
| Third-party library | `context7` | Up-to-date library docs |
| GitHub project code | `zread` or `gh-repos` | Direct repo access |
| Bug/issue investigation | `gh-issues` → `gh-pull` | Find known issues and fixes |
| Complex synthesis needed | `sequential-thinking` | Multi-step reasoning |

## Key Patterns (just examples, not set in stone or exhaustive)

**API Research**: `microsoft-docs`/`context7`/`web-search-prime` → `gh-repos search_code` for implementations

**Bug Investigation**: `gh-issues search` → `gh-pull search` for fixes → `web-search-prime` for workarounds

**Library Evaluation**: `context7` → `gh-issues list` (activity) → `web-search-prime` (sentiment)
